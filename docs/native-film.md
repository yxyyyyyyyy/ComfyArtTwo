# 原生动态视频与真人风格制作

幕间保留 Agent、图片、视频和自由画布的通用创作能力。下面介绍视频的扩展制作流程，适用于动漫、写实真人风格等短片，不限定作品题材。写实真人风格中的人物和场景由 AI 生成。

## 两种制作入口

**页面自动导演**：在视频制作页打开「多镜头 / 配音字幕制作」，提交自己的故事，生成约 30 / 60 秒的动作样片计划，再逐镜生成、配音和合成。可以先检查计划再制作。普通页面分镜任务需要保持页面运行；刷新后可接回已保存的任务和结果。

**后台完整制作**：在本地准备 `productions/<任务编号>/episode.json`，由 `deploy/render-directed-film.py` 执行配音、参考图、关键帧、原生视频与合成。后台任务独立运行，页面可以关闭或刷新后重新查看进度。已验证三分钟完整制作：36 段各 5 秒的原生动态视频，合成为 720 × 1280、24 fps 成片，含中文角色配音、字幕和音效。动漫与写实真人风格使用相同流程；页面目前没有三分钟自动导演选项。

这些是不同的执行方式。后台长视频仍需要整理制作清单和人工检查，不是输入任意长剧本后自动完成全部制作与质检。

## 准备清单与运行环境

制作清单保存在本地，不随源码提交。主要字段如下：

- `id`、`title`、`output_filename`：任务编号、片名和成片文件名；不同版本使用不同编号与输出目录。文件名只能是文件名，不包含目录。
- `native_only: true`、`target_seconds`：采用原生动态视频及目标总时长；镜头时长应覆盖目标时长。
- `width`、`height` 与 `native_width`、`native_height`：分别控制成片与模型生成尺寸；合成时会缩放、裁切，输出尺寸不等于原生生成尺寸。
- `keyframe_width`、`keyframe_height`、`image_steps`：参考图、关键帧尺寸及参考图编辑工作流的采样步数。
- `anchors`：带 `id` 和 `prompt` 的角色、场景参考图描述。
- `scenes`：按顺序列出镜头的 `id`、`title`、`location`、`references`、`keyframe`、`motion`、`native_seconds` 等信息。`references` 引用角色或场景参考图编号。
- `continue_previous`：从上一镜头实际生成视频提取末帧接续，要求前后镜头的 `location` 一致；首镜头不能使用此项。换地点或需要全新构图时使用独立关键帧。
- `keyframe_mode: "t2i"`、`keyframe_seed`：可选，使用文生图生成独立构图并固定其种子；默认关键帧通过参考图编辑生成。
- `narration`：对白与旁白，包含 `id`、`role`、`text`、`speaker`、`tone`、`beat` 等信息。`beats` 指定各段的 `id`、`title`、`start`、`end`，配音按实际声音长度安排在段内。

当前后台脚本使用 Z-Image Turbo 生成参考图，Qwen Image 2.1 编辑关键帧，MiniMax H3 生成图生视频，Qwen3-TTS 提供角色配音。对应的工作流、模型、编码器、VAE 与所需节点需要提前安装，具体文件见 `workflows/`。修改提示词不会安装缺失的依赖。

生成和合成环境还需 PyAV、NumPy、Pillow、requests、SciPy、soundfile 与 imageio-ffmpeg，以及单独配置的角色配音环境。中文烧录字幕需要可用的中文字库；当前合成脚本指定 Microsoft YaHei。Windows 示例启动器约定运行根目录下具有 `.venv`、`speech` 和 `ComfyUI`，可通过 `-Root` 指定自己的运行根目录：

```powershell
.\deploy\start-directed-film.ps1 -Id my-film -Root 'C:\path\to\runtime'
```

将示例路径替换为实际路径，并先准备 `productions/my-film/episode.json`。启动器注册 `ComfyArt-Episode-my-film` 计划任务并启动制作；不是通用的一键安装命令。它默认连接当前运行环境的 `http://127.0.0.1:8188`。

## 另做一个真人风格版本

1. 保留现有作品，另建项目、制作编号和素材目录。只修改项目名称或创作备注不会重制已有画面。
2. 重新编写角色与场景参考图提示词：统一年龄、发型、服装、自然皮肤、实景光线与镜头语言，清除动漫、插画、线稿和赛璐璐等冲突描述。
3. 用新参考图重新生成关键帧和动作视频。更换风格需要重制画面，不是给旧动画套一个真人滤镜。
4. 如果对白文本、音色、语气与语言都不变，可将原版本的 `voice/` WAV 与 `voice-manifest.json` 复制到新任务的 `voice/`。配音脚本会核对缓存，匹配的声音直接复用；重新生成的语音清单记录当前输出路径。
5. 先检查角色参考图和一小段含配音的画面，再检查关键情节与完整成片。当前没有自动生成并评审风格版本的页面按钮。

镜头提示先说明景别、构图与一个能在镜头时长内完成的动作，再补充必要的人物信息。只拍手、纸张或包的镜头，应限定近景范围，避免把完整人物描述反复加入道具特写。照片中的人物是纸上的静态图像，动作来自手、纸张与光影；镜子、照片和闪回中的服装与身份要分别检查。

## 进度、暂停与恢复

后台输出位于 ComfyUI 的 `output/comfyart/<任务编号>/`。`progress.json` 记录阶段、当前镜头、完成数量、采样状态和任务编号；`worker.out.log`、`worker.err.log`、`voices.log` 与 `render.log` 用于排查对应阶段。

- `GET /comfyart/video/production/<任务编号>`：查询状态与已完成素材。
- `POST /comfyart/video/production/<任务编号>/control`，请求体 `{"pause": true}`：请求暂停该任务。
- 同一接口提交 `{"pause": false}`：调用已注册的 Windows 计划任务继续制作。未注册任务或其他运行环境不能仅通过此接口启动后台制作。

暂停是一个过程，需要等待工作进程停止后再更改素材。暂停只取消该任务自己的生成请求，不会全局中断其他生成队列。断线时先查询原任务，避免重复提交；模型加载阶段没有可用百分比时仅展示实际阶段。

## 局部重拍与成片检查

局部重拍目前需要人工管理本地清单和素材。先暂停并确认任务停止，将需重拍镜头的旧视频与对应的 `clip-<镜头编号>-accepted.json` 验收记录一并移到独立的复核目录；如果关键帧也需重制，将该镜头的旧关键帧一并移出工作目录。随后更新动作或关键帧提示词。已经验收的镜头会复用，单改提示词不会自动使它失效；仅移走验收记录，也可能重新找到并复用旧候选视频。

如果后续镜头使用 `continue_previous`，还需处理受影响的接续镜头及缓存的 `key-<镜头编号>_from-video.png`，以便重新从替换后的视频提取实际末帧。不要只替换首镜头而继续使用其旧末帧。恢复后保留未受影响的素材继续制作。

成片合成缓存包含清单、语音清单、验收记录和原生视频文件信息；更换已验收视频后会刷新缓存，损坏或未完成的缓存片段会重制。这不会代替生成阶段的验收记录管理，也不会自动判断哪些剧情需要重拍。

`deploy/render-directed-timeline.py` 保持画面原速，裁切各段到指定时长，不用静图、循环或末帧停留补足时长。旁白过长时最多允许小幅加速；当前上限为 1.18 倍，超过预算会要求精简文本。字幕按配音时间排布，成片混入角色声音、可用的原生环境音和氛围音效。

完成后输出视频、`subtitles.ass`、`timeline.json` 与 `verification.json`。成片导出检查目标时长、尺寸与音轨是否存在；生成阶段通过抽取视频帧检查可解码性和画面变化。这些检查不能证明动作正确、角色一致或剧情完整。应另行观看人物、服装、道具、照片内容、镜面关系和情节揭示时机；当前也不保证对白口型同步或电视剧级别的连续表演。

## 源码与创作数据

公共仓库只保存源码、通用工作流和说明文档。自己的项目、故事、制作清单、角色参考图、配音、视频、数据库与验收截图保留在本地。`productions/`、`artifacts/` 与运行时数据目录已加入忽略规则；不要用强制添加绕过规则上传创作内容。

原项目来源、保留功能与许可证见 [项目说明](../README.md)；基础安装与环境约定见 [部署说明](../README.deploy.md)。
