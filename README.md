# 幕间 · MUJIAN STUDIO

基于 ComfyUI 的通用 AI 创作工作台，将 **Agent 创作、图片制作、视频制作、自由画布** 拆分为独立页面。既可以直接生成图片与视频，也可以让 Agent 调用工具，再到画布中整理素材和完成设计。

本项目基于 [jtydhr88/ComfyArt](https://github.com/jtydhr88/ComfyArt) 二次开发，使用 ComfyUI、React 和 tldraw，保留原项目的版权与许可证。仓库名为 **ComfyArtTwo**，应用界面品牌为 **幕间**；原有 `/comfyart/` 地址和数据格式继续保留，兼容已有项目。

## 核心功能

- **Agent 创作**：通过对话规划设计，调用画布与生成工具；保留上游 Agent 和技能入口。
- **图片制作**：文生图、参考图生成、图像编辑，以及按已安装模型提供的抠图、超分、擦除、扩图等工具。
- **视频制作**：文生视频、图生视频、分镜制作、旁白字幕与成片合成；支持查看进度和复用已完成素材。
- **自由画布**：组织图片、视频、文字和设计元素，保留原有项目、图层、排版、素材和导出能力。
- **项目管理**：查看最近项目、搜索、继续创作及管理作品。

图片和视频页面提供常用生成与编辑操作；图层、擦除、扩图、排版及其他精修工具可在自由画布中使用。具体模型能力取决于已安装的权重与节点，Agent 还需配置并启用可用服务。

## 如何使用

1. 在首页选择 **Agent 创作、图片制作或视频制作**，新建一个项目。
2. 在对应页面描述需求、添加参考素材并设置参数；图片和视频分别保存自己的输入与设置。
3. 在作品预览区查看结果，或打开 **自由画布** 继续编辑、组合与排版。
4. 回到项目列表可继续已有创作；需要独立的一套素材时，新建项目。

**一个项目拥有自己的画布和素材，不会为每个生成任务另建画布。** 同一项目内，Agent、图片和视频页面使用同一套项目素材；画布可以容纳多次任务的结果。只需生成或下载单张图片、单段视频时，可以直接在对应页面完成。

在视频制作页打开「多镜头 / 配音字幕制作」，粘贴自己提供的故事或剧本，选择「AI 自动分镜并制作」，可完成导演计划、逐镜生成及配音合成。也可先只生成计划，确认后制作。

漫剧是视频能力的一种使用方式，剧本、角色声音、分镜和合成属于可选扩展流程。项目同样适用于海报、品牌素材、社交媒体配图、设计排版和短视频。

## 本项目的改进

- 重新设计品牌、首页和固定导航，Agent、图片、视频作为主要创作入口。
- 按能力拆分独立页面：Agent 对话与执行、图片生成编辑、视频参数与预览；底层工作流继续复用。
- 增加 AI 自动导演：输入自己的故事，自动安排约 30 / 60 秒动作样片的镜头、场景、运镜与简短旁白。
- 同场景连续动作可衔接上一镜头末帧；自动导演合成保持画面正常速度，旁白过长时提示修订。
- 增加可见的制作阶段、场景素材预览、断线恢复和失败重试。
- 增加剧本修订稿、角色配音信息和成片播放页面，作为视频制作的扩展流程。
- 完善模型资源交接、任务编号保存及文件占用处理，减少重复生成。

## 本地项目与数据

GitHub 仓库用于维护程序源码、工作流、构建文件和公共文档。**你创建的项目、对话、剧本、制作清单、生成图片、视频、配音及导出文件属于本地数据，不随源码提交。**

这些内容保留在自己的运行环境中；`productions/`、项目数据目录、数据库、输出与导出目录、验收截图均已加入忽略规则。应用没有自动上传创作内容到 GitHub 的功能。调用本地还是外部模型服务取决于自己的服务配置，与 GitHub 代码同步是两件事。

## 安装与运行

先准备可以运行的 ComfyUI 环境，在 `ComfyUI/custom_nodes` 下克隆：

```sh
git clone https://github.com/yxyyyyyyyy/ComfyArtTwo.git ComfyArt
cd ComfyArt
```

使用 **ComfyUI 所在的 Python 环境** 安装依赖：

```sh
python -m pip install -r requirements.txt
```

重启 ComfyUI，打开 <http://127.0.0.1:8188/comfyart/>。仓库包含构建后的前端；修改源码后重新构建：

```sh
npm ci
npm run build
npm run test:frontend
```

模型权重、节点与运行环境需要单独准备，源码齐全不代表所有可选功能均已安装。环境配置、开发构建和示例视频流程见 [部署说明](README.deploy.md)。部署脚本中的 SSH 别名、盘符及目录应按自己的环境配置。

## 目录

- `src/studio/`、`src/styles/studio.css`：通用创作导航、项目总览与扩展视频流程。
- `src/ui/`：制作任务、角色与成片交互，以及保留的画布工具。
- `api/`、`bot/`、`workflows/`：后端接口、Agent 和 ComfyUI 工作流。
- `deploy/`：本地部署、配音、动画制作、字幕混音与合成脚本。
- `tests/`：回归测试。

本仓库不包含本地模型权重、用户项目数据库、对话、剧本、生成媒体和私密配置。`docs/` 中保留上游公开宣传素材，不包含本地项目展示截图。

自动导演参考 [comfyui-auto-drama](https://github.com/qiukaihui/comfyui-auto-drama) 的链式镜头流程、[AutoVid](https://github.com/hanmengkai/autovid-oss) 的分阶段制作方式和 [ViMax](https://github.com/DeepTransform/vimax) 的镜头与连续性规划思路。当前以共享人物描述与同机位末帧接续保持连续性，换机位时的人物一致性仍受模型能力影响。
