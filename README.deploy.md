# 部署与开发

幕间是基于 [ComfyArt](https://github.com/jtydhr88/ComfyArt) 二次开发的通用 AI 创作工作台。Agent、图片、视频和画布功能保留，漫剧制作作为综合演示与扩展工作流提供。版权与各项许可证保持完整。

## 基础安装

先准备可正常启动的 ComfyUI 环境，将本仓库放到 `ComfyUI/custom_nodes/ComfyArt`，使用 ComfyUI 对应的 Python 安装依赖：

```sh
python -m pip install -r requirements.txt
```

启动 ComfyUI 后打开 <http://127.0.0.1:8188/comfyart/>。保留原来的地址、项目数据库与素材格式，已有项目可以继续使用。

模型权重和可选节点需要另行安装。原有功能与依赖说明见 [上游中文文档](README.zh.md) 和 `workflows/`；可使用 `python deploy/audit-workflows.py` 检查工作流准备情况，检查脚本中的服务地址应对应当前环境。

## 前端开发

```sh
npm ci
npm run build
npm run test:frontend
```

`src/home/` 提供首页与项目入口；`src/studio/CreationPages.tsx` 提供独立的 Agent、图片和视频页面，`src/studio/` 同时提供通用导航和扩展制作页面；`src/ui/` 保留画布、Agent 面板与生成工具。`dist/` 为构建后的静态文件。

仅修改前端时，可以更新静态资源后刷新页面，无需重启生成服务。应先同步新的散列资源，最后更新 `index.html`，保留已打开页面需要的旧资源。

## 创作入口

- Agent 创作：读取需求、参考图与技能，调用工具完成设计。
- 图片制作：使用原有图片模式及图像编辑工具。
- 视频制作：使用原有视频模式，支持文生视频、图生视频及长剧本分镜流程。
- 自由画布：组织和编辑已有素材、文字及设计元素。

图片与视频页面各自保存提示词、参考素材与参数，直接调用对应生成或编辑流程。Agent 页面保留技能、参考文件与上下文对话，不会把其他页面的输入自动混入当前任务。已安装状态会检查主模型、编码器、VAE 与所需 LoRA，避免把缺少依赖的工作流标成可用。

## 项目与进度

每个项目管理自己的画布、素材与任务记录；Agent、图片和视频页面共享该项目的素材，不为每次生成任务另建项目。项目、快照与对话保存在 ComfyUI 用户目录下的 `__comfyart/data.db`。更新应用时保留用户目录、模型和输出素材。

GitHub 仅同步源码与公共文档。本地项目、剧本、制作清单、数据库、生成媒体和导出文件不提交；`.gitignore` 已排除相应目录与数据库文件。不要为了提交源码而强制添加这些被忽略的文件。

制作任务保存编号与已完成素材。网络中断时先查询原任务，避免重复提交；工作台显示实际阶段与可用的采样进度，不估造模型加载百分比。普通分镜流程请保持页面运行；刷新后可接回已保存的任务。

隐藏画布或剔除不可见文字节点时，不将不可测量的文字尺寸写回项目。打开自由画布可使用原有图层、排版、图片编辑与导出工具。

## 自动导演样片

视频工作台可对用户提供的故事生成约 30 / 60 秒的短镜头计划。每镜生成 5 秒原生视频，包含动作、景别或运镜、场景编号与简短旁白。导演计划及原稿随项目保存；返回格式、镜头数、接续关系或旁白长度无效时会自动请求一次修正，再显示具体错误。

同场景、同机位的连续动作可提取上一镜头的末帧作为下一镜头首帧。转场和换机位使用独立镜头及共享人物描述，当前不保证跨机位身份完全一致。该提取过程在浏览器执行，普通多镜头任务仍需保持页面打开；刷新后可继续使用已保存的结果和任务编号。

自动导演模式下合成不延长视频画面，较长配音只允许小幅加速；超过范围时要求缩短旁白或增加镜头。手动分镜保留原有时长处理。若自动导演已有镜头开始生成，先完成当前版本或创建修订项目，再重新规划。

## 视频与漫剧演示

剧本、角色对白与制作清单属于本地项目数据。可在已忽略的 `productions/<任务编号>/episode.json` 中准备自己的清单，交给制作脚本运行；仓库不附带用户的实际创作内容。图片、动画片段、配音、字幕和剪辑可按任务组合，并不限定项目只能制作漫剧。

`deploy/render-comic-episode.py` 按场景生成素材，`deploy/story-speech.py` 提供 Qwen3-TTS 角色配音，`deploy/render-comic-timeline.py` 按实际声音时长组织字幕与混音，并合成为一条视频。示例采用人物动画片段与动态漫画结合；普通图片、设计和单段视频不需要使用此流程。

剧本修订稿单独保存；已有生成记录时，可以带到新项目制作，保留上一版成片。角色页面展示已制作的音色与对白，创作备注供修订参考，不会即时更改已有声音或画面。

独立后台整集任务支持收起、刷新后继续读取进度。暂停只作用于对应任务。已完成素材会校验和复用，失败时保留任务编号；最终输出使用版本化文件名，避免覆盖正在播放的文件。

需要全部采用生成视频的长片，可使用 `deploy/render-directed-film.py` 读取本地制作清单。清单指定角色与场景参考、镜头动作、同场景接续、分段配音和目标时长。`continue_previous` 镜头从上一段实际视频提取末帧；其他镜头使用共享参考生成关键帧。换场镜头可设置 `keyframe_mode: "t2i"` 独立生成新构图，`keyframe_seed` 可固定该关键帧的种子。该后台流程目前通过本地清单启动，不是视频页面自动导演的时长选项。

```powershell
.\deploy\start-directed-film.ps1 -Id my-film
```

此命令读取已忽略的 `productions/my-film/episode.json`，创建对应后台任务；示例根目录可通过 `-Root` 调整。运行环境需要 PyAV、NumPy、Pillow、requests，以及合成所需的 SciPy、soundfile、imageio-ffmpeg 和角色配音环境。`deploy/render-directed-timeline.py` 按实际声音长度排布字幕和混音，保持视频原速，不用静图、循环或末帧延长来补足时长。替换原生片段后会刷新合成缓存，未完成的缓存片段会重新生成。视频会检查可解码性、时长和画面变化；这种检查只能发现近似静止的视频，剧情、动作与角色一致性仍需人工观看确认。

## 部署脚本

`deploy/` 中保留了一套示例部署、源码同步、模型下载、配音与视频合成脚本。它们包含示例 SSH 别名、磁盘路径、服务端口及任务名称，使用前应按自己的环境配置。PowerShell 脚本面向 Windows 示例环境，基础插件安装不依赖这套远程部署脚本。

`deploy/push-ui.py` 演示无需重启服务的前端更新；`deploy/sync.py` 将部署包上传到自己的运行环境，不执行 GitHub 提交或推送。部署包与公开仓库应分开管理，使用前检查打包范围；不要将模型目录或项目数据库作为代码更新覆盖。

可选的 `deploy/cache-video-models.py --profile image` 会将图像流程权重复制并校验到可配置缓存目录，保留原始模型文件，同时合并现有视频缓存配置。默认 `--profile video` 维持视频缓存行为。配置生效需要生成服务加载对应配置文件；只在生成队列空闲时重启服务。
