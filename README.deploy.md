# 部署与开发

幕间是基于 [ComfyArt](https://github.com/jtydhr88/ComfyArt) 二次开发的通用 AI 创作工作台。Agent、图片、视频和画布功能保留，漫剧制作作为综合演示与扩展工作流提供。版权与各项许可证保持完整。

## 基础安装

先准备可正常启动的 ComfyUI 环境，将本仓库放到 `ComfyUI/custom_nodes/ComfyArt`，使用 ComfyUI 对应的 Python 安装依赖：

```sh
python -m pip install -r requirements.txt
```

启动 ComfyUI 后打开 <http://127.0.0.1:8188/comfyart/>。保留原来的地址、项目数据库与素材格式，已有项目可以继续使用。

模型权重和可选节点需要另行安装。原有功能与依赖说明见 [上游中文文档](README.zh.md) 和 `workflows/`；可使用 `python deploy/audit-workflows.py` 检查工作流准备情况，检查脚本中的服务地址应对应当前环境。

## 前端开发

```sh
npm ci
npm run build
npm run test:frontend
```

`src/home/` 提供首页与项目入口；`src/studio/CreationPages.tsx` 提供独立的 Agent、图片和视频页面，`src/studio/` 同时提供通用导航和扩展制作页面；`src/ui/` 保留画布、Agent 面板与生成工具。`dist/` 为构建后的静态文件。

仅修改前端时，可以更新静态资源后刷新页面，无需重启生成服务。应先同步新的散列资源，最后更新 `index.html`，保留已打开页面需要的旧资源。

## 创作入口

- Agent 创作：读取需求、参考图与技能，调用工具完成设计。
- 图片制作：使用原有图片模式及图像编辑工具。
- 视频制作：使用原有视频模式，支持文生视频、图生视频及长剧本分镜流程。
- 自由画布：组织和编辑已有素材、文字及设计元素。

图片与视频页面各自保存提示词、参考素材与参数，直接调用对应生成或编辑流程。Agent 页面保留技能、参考文件与上下文对话，不会把其他页面的输入自动混入当前任务。已安装状态会检查主模型、编码器、VAE 与所需 LoRA，避免把缺少依赖的工作流标成可用。

## 项目与进度

项目、快照与对话保存在 ComfyUI 用户目录下的 `__comfyart/data.db`。更新应用时保留用户目录、模型和输出素材。

制作任务保存编号与已完成素材。网络中断时先查询原任务，避免重复提交；工作台显示实际阶段与可用的采样进度，不估造模型加载百分比。普通分镜流程请保持页面运行；刷新后可接回已保存的任务。

隐藏画布或剔除不可见文字节点时，不将不可测量的文字尺寸写回项目。打开自由画布可使用原有图层、排版、图片编辑与导出工具。

## 视频与漫剧演示

`productions/cellar-episode-01/` 是综合演示，保留示例剧本、角色对白与场景规范。它展示图片、动画片段、配音、字幕和剪辑的组合，并不限定项目只能制作漫剧。

`deploy/render-comic-episode.py` 按场景生成素材，`deploy/story-speech.py` 提供 Qwen3-TTS 角色配音，`deploy/render-comic-timeline.py` 按实际声音时长组织字幕与混音，并合成为一条视频。示例采用人物动画片段与动态漫画结合；普通图片、设计和单段视频不需要使用此流程。

剧本修订稿单独保存；已有生成记录时，可以带到新项目制作，保留上一版成片。角色页面展示已制作的音色与对白，创作备注供修订参考，不会即时更改已有声音或画面。

独立后台整集任务支持收起、刷新后继续读取进度。暂停只作用于对应任务。已完成素材会校验和复用，失败时保留任务编号；最终输出使用版本化文件名，避免覆盖正在播放的文件。

## 部署脚本

`deploy/` 中保留了一套示例部署、源码同步、模型下载、配音与视频合成脚本。它们包含示例 SSH 别名、磁盘路径、服务端口及任务名称，使用前应按自己的环境配置。PowerShell 脚本面向 Windows 示例环境，基础插件安装不依赖这套远程部署脚本。

`deploy/push-ui.py` 演示无需重启服务的前端更新；`deploy/sync.py` 打包源码，排除模型、用户数据、构建依赖、私密配置和验收产物。不要将模型目录或项目数据库作为代码更新覆盖。
